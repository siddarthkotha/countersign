# Seat: Grok (pasted 2026-09-01)

## 1. DEPTH
The "verdict is baked into the seed" objection is fatal and the plan never escapes it. A judge who reads the seed JSON or the decision table will conclude the freeze is theater. Only conversational facts: verbatim amounts, name claims, pressure phrases, consistency failures across turns, talk-over counts, response latency to challenges. Rescue: story-ledger diffs with both verbatim substrings; timing signals labeled behavioral; adaptive challenge selection from what the caller asserted this session. Ranking: 1 story ledger (mandatory); 2 adaptive challenge; 3 timing markers; 4 stalling library; 5 corpus (useful for CI, useless for live trust). Missing: a live visible fact ledger that highlights contradictions the moment the second utterance lands, two spans side by side; server-side re-evaluation that injects a second independent challenge after the browser decided and shows convergence/divergence; an "unknown knowledge" path (if the caller invents a fact not in the seed, treat it as an open question forcing an additional check rather than ignoring it; without this any off-script judge breaks the table in under a minute). The table is first-match-wins and public; an attacker avoids the thresholds.

## 2. POSITIONING
~1,466 participants and 330 teams registered on day one. Presentation weighted first. Business value and originality mediocre because the "policy engine not LLM" claim is published prior art. Entries that beat it: consumer/accessibility agents magical in ten seconds ("EverCall — Jarvis for Grandma" already in early community votes); agents exercising mid-session tool/prompt updates, session resumption, multi-language in one continuous call; demos that move a real sandbox system instead of a "simulated" banner. Per criterion: Presentation, the cheat sheet and simulated banners scream hackathon demo; remove the cheat sheet, force discovery by speaking. Business value, no consumer path; quantify cost-of-false-positive and show loss-avoidance with labeled sources. Application, under-uses live configuration updates, session resumption, neural turn detection; mid-call prompt and tool-list mutation driven by the engine's state, live. Originality, the implementation is still a seeded table; ship the story ledger as the primary visual. Prior lablab winners solved an immediately legible problem in fifteen seconds; this entry's first fifteen seconds are a mic banner and a cheat sheet.

## 3. IMPROVISATION
20 moves, notable: silence → add "still there?" at 12 s; gibberish → never stage; another language → must detect and go OUT_OF_SCOPE; playing Dana but changing amount → freeze acceptable if the ledger shows it; refusing → ESCALATE; arguing after freeze → containment, never re-open; hanging up mid-check → server must still write the incident; demanding a human → explicit ESCALATE; social-engineering after freeze → stay SEALED, never call stage tools (critical); claiming to be Marcus → restart intake (missing rule); correct knowledge + wrong SSO → freeze; constant talk-over → hard stop after pressure; playing a cloned voice → ignored by design; rapid-fire amount changes → accumulate; approved-in-unknown-system → context failure; bail-money scenario in corporate mode → mode switch or OUT_OF_SCOPE (missing); tab left open → idle disconnect. Corpus must include: silence, language switch, post-freeze argument, correct-knowledge-wrong-SSO, amount drift, "I'm testing."

## 4. ARCHITECTURE ATTACKS
Malicious browser lies about the logs it submits, suppresses barge-in events, forges timestamps, calls tools outside the allowlist (UI shows false progress), keeps the socket open past the cap. LLM tool: the model chooses when to call and which substring; close it by making knowledge extraction pure deterministic code over the last N user transcripts; the LLM only gets a phrasing goal, never a tool that writes evidence. Wifi: the worker drops frames, the 15 fps throttle looks broken, a dropped speech-started event leaves the agent talking over the judge; fall back to main-thread audio on high packet loss, show measured p50/p95 on screen, an "audio degraded" banner. Ephemeral tokens with a hard max session length are correct. Table: an attacker supplies an identity, a request passing context, correct knowledge answers, never triggers three failures; pressure alone never blocks so pure urgency works; needs a hard "any consistency failure after a knowledge challenge → FREEZE" rule that later correct answers cannot bypass.

## 5. UX, VOICE, CHARACTER
First five seconds: mic dialog, "simulated" banners, a cheat sheet telling them what to say: the opposite of a confident product demo. The freezing profile will also look broken when network jitter freezes it for real. The "WIRE FROZEN" banner will still read as alarm. Keynote: single full-bleed call view, evidence cards as subtle overlays, no cheat sheet, no "simulated" text until asked. Character is a liability with a security jury: "friendly and cooperative, never showing its hand" reads as deceptive; security buyers want a professional gate, not a helpful assistant secretly containing them. The one-beat silence before the verdict is the only moment that works.

## 6. WHAT WOULD BEAT IT
A pure consumer "family safety" agent on a grandparent's phone: multi-language, mid-session updates, a single adaptive family-fact challenge from a user-uploaded knowledge base, never stages any payment, only notifies the family and keeps the caller engaged; no enterprise identity, no seeded mocks, no reverse-engineerable table; one continuous call where the judge plays the scammer. Would switch. The current plan is a beautifully engineered theater piece whose core claim is public prior art and whose live evidence surface is too thin.
