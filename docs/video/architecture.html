Architecture, 2:35 to 2:50

The engine decides every verdict.
The model only phrases it.

🟢 Deterministic policy engine (a finite-state machine) reads structured evidence: quoted transcript facts, confirmed fields, check results. It computes the verdict from that evidence alone. 🔵 The language model is handed that state and a phrasing goal; it chooses words for the conversation, and it is never given a verdict to decide or a tool to act with.

Law 2
A verified request only ever reaches STAGE plus an independent second approval. Voice alone never releases a transfer. A fraud call only ever reaches FREEZE.
